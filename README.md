
# Web Technology - Assignment 01

## Overview
This repository contains the submission for Assignment 01 of the Web Technology course. The objective of this assignment is to design a clean, professional, and well-structured personal resume webpage using semantic HTML.

## Repository Structure
* `index.html` — The primary resume webpage structuring personal details, work experience, education, technical projects, and skills.
* `README.md` — Project documentation and setup instructions.
* `LICENSE` — Open-source MIT licensing information.

## Sections Included
* **Contact Information:** Full name, clickable email link (`mailto:`), phone number, and location.
* **Professional Summary:** A concise career overview focusing on full-stack web development, REST APIs, and database architecture.
* **Work Experience:** Campus Ambassador role at TalentBeacon covering student outreach and communication.
* **Education:** Academic details and current enrollment in BS Information Technology at PUCIT.
* **Technical Projects:**
  * Proactive Insider Threat Mitigation Using Zero Trust Architecture & Honeytokens (C++)
  * MediCore Emergency Response Management System (SQL / RDBMS)
  * Hospital Management System (Java, OOP, MVC)
  * Frontend Web Applications (React, REST APIs)
* **Skills, Tools & Technologies:** Categorized listing of programming languages, web stacks, databases, and core concepts.
